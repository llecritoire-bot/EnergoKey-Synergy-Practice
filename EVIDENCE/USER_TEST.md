## Сценарий

1. Открыть Level 1 в Play Mode.
2. Установить Game View `1024×768 (4:3)`.
3. Проверить видимость и доступность четырёх экранных кнопок управления у нижней границы.
4. Зафиксировать обнаруженное отклонение.
5. Исправить позиционирование D-pad без изменения механики управления.
6. Повторить тот же визуальный шаг при `1024×768 (4:3)`.

## UX-01 — нижняя кнопка D-pad обрезалась в 4:3

| Поле | Фактическое наблюдение |
|---|---|
| Ожидаемое поведение | Все четыре кнопки D-pad целиком видны и находятся внутри нижней границы Game View. |
| Состояние до | Кнопка со стрелкой вниз находилась слишком низко: её нижняя часть выходила за видимую область 4:3. |
| Доказательство до | `screenshots/PP13_10_BeforeUserFix.png` |
| Причина | D-pad был привязан к нижнему правому углу, а вертикальная позиция нижней кнопки составляла 15 px при размере кнопки 72×72 px. |
| Исправление | В `SceneBootstrap.CreateControls` весь блок поднят на 35 px: Left/Right `y=95→130`, Up `y=175→210`, Down `y=15→50`. Размер и привязка кнопок не менялись. |
| Commit исправления | В tagged-поставке ревизия идентифицируется аннотированным тегом `pp-pm13-release`; полный hash получают командой `git rev-list -n 1 pp-pm13-release`. Разрешение тега является отдельной проверкой упаковки. |
| Состояние после | При том же Game View `1024×768 (4:3)` кнопка со стрелкой вниз отображается целиком; четыре кнопки остаются раздельными и читаемыми. |
| Доказательство после | `screenshots/PP13_11_AfterUserFix.png` |
| Результат повторной проверки | PASS |
