## Сценарий наблюдения

1. Предоставить проект пользователю, ранее с ним не знакомому.
2. Не объяснять устно управление, цель и особое правило.
3. Предложить самостоятельно ознакомиться с экранными подсказками и начать игру.
4. Проверить понимание четырёх экранных кнопок управления.
5. Проверить применение правила: сначала собрать все кристаллы, затем войти в открытый выход.
6. Пройти Level 1.
7. Открыть Pause и продолжить игру через Resume.
8. Зафиксировать затруднения и замечания.

## Технические исправления, выполненные до внешней проверки

Отклонения `UX-01` и `UX-02` были выявлены технической проверкой интерфейса и устранены до пользовательского наблюдения. Они не выдаются за замечания внешнего участника.

### UX-01 — нижняя кнопка D-pad обрезалась в 4:3

| Поле | Фактические данные |
|---|---|
| Исходное состояние | В 1024×768 нижняя часть кнопки со стрелкой вниз выходила за видимую область. |
| Причина | Вертикальная позиция Down составляла 15 px при размере кнопки 72×72 px. |
| Исправление | Блок D-pad поднят на 35 px: Left/Right `y=95→130`, Up `y=175→210`, Down `y=15→50`. |
| Доказательство до | `screenshots/PP13_10_BeforeUserFix.png` |
| Доказательство после | `screenshots/PP13_11_AfterUserFix.png` |
| Повторная техническая проверка | PASS: четыре кнопки полностью видны и раздельны в 1024×768. |

### UX-02 — пересечение элементов Level Select в 4:3

| Поле | Фактические данные |
|---|---|
| Исходное состояние | В 1024×768 подсказка об открытии следующего уровня пересекалась с кнопкой «Назад». |
| Исправление | BackButton поднята с `y=-275` до `y=-200`; anchors подсказки перенесены в диапазон `0.02–0.09`. |
| Доказательство до | `responsive/BEFORE_1024x768_LevelSelect_overlap.png` |
| Доказательство после | `responsive/RESP_1024x768_LevelSelect.png` |
| Повторная техническая проверка | PASS: overlap отсутствует; автоматическая проверка границ пройдена во всех трёх форматах. |
