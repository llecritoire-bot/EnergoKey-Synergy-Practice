# Проверка автоматической паузы при потере фокуса

- Статус: `PASS`
- Дата: 27 октября 2026 года
- Сборка: macOS Standalone Development, Unity `6000.6.2f1`, версия игры `1.0.0`
- Физическая среда: MacBook Air, Apple M3, arm64
- Начальная сцена диагностической сборки: `Level1`

## Фактическая последовательность

1. Отдельная macOS-сборка запущена сразу на Level 1; игровой таймер работал.
2. Окно приложения было реально свёрнуто стандартной кнопкой macOS.
3. Runtime-лог зарегистрировал `hasFocus=False`, затем системное событие `paused=True` при состоянии игры `Playing`.
4. После возврата окна отображалась панель «ПАУЗА», а игровой таймер был остановлен.

Доказательства:

- `logs/mac-focus-loss-events.log` — компактная выборка фактических runtime-маркеров;
- `logs/mac-focus-probe-runtime.log` — полный runtime-лог диагностического запуска;
- `screenshots/PP12_13_FocusLossAutoPause.png` — реальный снимок окна macOS Standalone после возврата из свёрнутого состояния.

Диагностическая сборка отличалась только порядком стартовой сцены (`Level1` первой), чтобы проверить lifecycle без ручной навигации. Игровой код и обработчики потери фокуса совпадают с основной сборкой. Сборка находится во временной папке и в итоговый ZIP не включается.
