# Авторы и ресурсы

## Проект

- Название: «Энергоключ».
- Версия: 1.0.0.
- Автор: студент.
- Назначение: учебный проект для практик ПМ.12 и ПМ.13.

## Графика и звук

«Создано автором работы специально для учебного проекта».

Все игровые PNG, иконка, рекламное изображение, макет страницы продукта и WAV-сигналы созданы программно скриптом `Tools/generate_original_assets.py`. Для синтеза использованы геометрические примитивы, градиенты, осцилляторы и огибающие.

Сторонние изображения, музыка, звуковые записи и платные наборы Unity Asset Store не использовались. Шрифтовые файлы в проект не копировались; подписи в Release-изображениях сохранены как часть растровых PNG.

Перечень лицензий сторонних медиаресурсов не добавлен, потому что такие ресурсы в поставку не входят.
