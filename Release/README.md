# Release «Энергоключ» 1.0.0

Эта папка содержит материалы версии 1.0.0 для оформления страницы продукта и подготовки отчётов. Это не самостоятельная сборка игры: исходный Unity-проект находится уровнем выше, а запуск начинается со сцены `Assets/Scenes/MainMenu.unity` в Unity 6000.6.2f1.

Графические и звуковые материалы созданы специально для учебного проекта с использованием программных средств. Способ генерации указан в `Docs/CREDITS.md`.

## Что проверять вместе с Release

Основные доказательства лежат не здесь, а в `../EVIDENCE`: там находятся матрица скриншотов, результаты тестов, Profiler до/после, внешняя пользовательская проверка и итоговый статус требований. Версию текущей Git-поставки можно получить командой из корня репозитория:

```text
git rev-parse HEAD
```

Финальную версию проверил новый пользователь, ранее не знакомый с проектом. Физическое Android/iOS-устройство не использовалось: Safe Area проверялась в Unity Editor, а демонстрационный ролик представлен storyboard.
