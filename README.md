# Энергоключ

Учебный Unity-проект для последовательного выполнения УП.ПМ.12, ПП.ПМ.12, УП.ПМ.13 и ПП.ПМ.13.

Текущий этап: рабочий прототип УП.ПМ.12.

- Unity: 6000.6.2f1
- Шаблон: 2D
- Ориентация: landscape
- Сцена прототипа: `Assets/Scenes/Prototype.unity`
- Управление: экранные кнопки, WASD или стрелки

Игрок собирает все энергетические кристаллы. До этого выход остаётся закрытым. Опасность отнимает одну из трёх жизней и возвращает игрока на старт. Собранные кристаллы сохраняются после повреждения в рамках текущей попытки.
