# Пакет задания для Codex — практика колледжа «Синергия»

Этот архив предназначен для разработки единого Unity-проекта, который последовательно закрывает:

1. УП.ПМ.12 — учебная практика «Программирование мобильных игр»;
2. ПП.ПМ.12 — производственная практика «Программирование мобильных игр»;
3. УП.ПМ.13 — учебная практика «Оформление игрового продукта»;
4. ПП.ПМ.13 — производственная практика «Оформление игрового продукта».

База практики: АНО ВО «Московский университет «Синергия» / колледж (СПО) «Синергия».

Титульные персональные данные студента не заполнять.

## Главный принцип

Нужно создать ОДНУ простую 2D-игру и развивать её по этапам, сохраняя историю Git. Не делать четыре несвязанных проекта.

## Выбранный максимально простой сценарий

Название: **«Энергоключ»**.

Жанр: 2D top-down arcade / collect-and-exit.

Игрок перемещает объект по плоской арене четырьмя экранными кнопками (для проверки в Editor дополнительно допускаются WASD/стрелки). На уровне нужно собрать все энергетические кристаллы, избегая статических опасных зон. Выход закрыт, пока не собраны все кристаллы. После сбора всех кристаллов выход открывается. У игрока 3 жизни. Контакт с опасностью отнимает жизнь и возвращает игрока в стартовую точку. При нуле жизней — поражение. Достижение открытого выхода — победа.

Уровни:
- Уровень 1: 3 кристалла, 2 опасности, простой маршрут.
- Уровень 2: 4 кристалла, 4 опасности, более плотное расположение.
- Уровень 3: 5 кристаллов, 6 опасностей, наиболее сложный маршрут.

Уровень 2 открывается только после победы на уровне 1. Уровень 3 — после победы на уровне 2. После победы на уровне 3 перехода к уровню 4 быть не должно.

Рекорд: лучший итоговый счёт. Рекомендуемая формула: собранные кристаллы × 100 + оставшиеся жизни × 50. Сохранять лучший результат.

Сохранять между запусками: открытые уровни, лучший счёт, громкость, факт просмотра обучения. Временные значения текущей попытки при старте новой попытки сбрасывать.
