# Генерация оригинальных ресурсов

Все PNG и WAV, перечисленные ниже, созданы скриптом `Tools/generate_original_assets.py` специально для учебного проекта «Энергоключ».

**Авторство:** «Создано автором работы специально для учебного проекта».

## Воспроизведение

```bash
[USER_HOME]/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  Tools/generate_original_assets.py
```

Генерация детерминирована (`SEED = 0xE11E6E7`), не скачивает сторонние материалы и использует Pillow, NumPy и стандартный модуль Python `wave`. Изображения строятся из геометрических примитивов, градиентов и программных эффектов. WAV создаются синтезом осцилляторов и огибающих.

## Визуальные параметры

- фон: `1280×720`, тёмная сине-графитовая палитра;
- Player: `256×256`, голубое энергоядро;
- crystal: `256×256`, жёлтый кристалл;
- hazard: `256×256`, красная статическая опасность;
- exit_closed / exit_open: `320×320`, серо-красный закрытый и зелёный открытый портал;
- ui_button: `640×192`, ui_panel: `720×440`;
- life / lock / pause / отдельные стрелки: `128×128`;
- arrows: `384×384`;
- `Release/icon_512.png`: строго `512×512`;
- `Release/promo_1280x720.png`: строго `1280×720`;
- `Release/product_page_mockup.png`: `1440×1800`, явно помечен как макет, а не скриншот игры.

Прозрачный фон сохранён у игровых спрайтов и UI-элементов. Рекламные материалы являются ключевым артом и макетом страницы продукта; они не выдаются за кадры игры или интерфейс Unity.

## Аудио

`collect.wav`, `error.wav`, `damage.wav`, `victory.wav`, `defeat.wav`, `button.wav` создаются как mono PCM, 16-bit, 44.1 kHz. В генераторе нет сторонних записей или семплов.
