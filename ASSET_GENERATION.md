# Генерация графических и звуковых материалов

Графические и звуковые материалы созданы специально для учебного проекта с использованием программных средств.

## Воспроизведение

Из корневого каталога проекта выполнить:

```bash
python3 Tools/generate_original_assets.py
```

Скрипт `Tools/generate_original_assets.py` использует фиксированное начальное значение `SEED = 0xE11E6E7`, не загружает сторонние материалы и сохраняет результат непосредственно в каталогах проекта. Для запуска необходимы Python 3, Pillow и NumPy; для WAV используется стандартный модуль `wave`.

Изображения создаются из геометрических примитивов, градиентов и программных эффектов. Звуковые сигналы формируются синтезом осцилляторов и огибающих без сторонних записей и семплов.

## Выходные файлы

Игровая графика сохраняется в `Assets/Resources/Art/`, звуковые сигналы — в `Assets/Resources/Audio/`, материалы выпуска — в `Release/`.

Основные параметры:

- фон: 1280×720, тёмная сине-графитовая палитра;
- Player: 256×256, голубое энергоядро;
- crystal: 256×256, жёлтый кристалл;
- hazard: 256×256, красная статическая опасность;
- exit_closed и exit_open: 320×320;
- ui_button: 640×192, ui_panel: 720×440;
- life, lock, pause и стрелки: 128×128;
- arrows: 384×384;
- `Release/icon_512.png`: 512×512;
- `Release/promo_1280x720.png`: 1280×720;
- `Release/product_page_mockup.png`: 1440×1800.

У игровых спрайтов и UI-элементов сохраняется прозрачный фон. Рекламные материалы являются ключевым изображением и макетом страницы продукта и не обозначаются как игровые скриншоты.

## Аудио

Файлы `collect.wav`, `error.wav`, `damage.wav`, `victory.wav`, `defeat.wav` и `button.wav` создаются в формате mono PCM, 16-bit, 44.1 kHz.
